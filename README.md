# 2026 TMLS: Why Your RAG Agent Is Confidently Wrong: Retrieval Choices That Actually Matter

Welcome to the landing page for the session `Why Your RAG Agent Is Confidently Wrong: Retrieval Choices That Actually Matter` at `Toronto Machine Learning Summit (TMLS) 2026`.

## What to Expect

This repo intends to provide an introduction to:

- Understanding how Vector retrieval (for RAG use cases) has limitations for certain use cases.
- Understanding how Graph retrieval (for RAG use cases) is ideal for providing factually correct answers.
- Understanding how Hybrid retrieval (for Hybrid RAG) can provide both factually correct and human-like answers.

## Hardware Prerequisites

You should only need your laptop.

## Software Prerequisites

- A Linux or Mac-based Developer’s Laptop 
  - Windows Users should use a VM or Cloud Instance
- Python Installed: version 3.10 **ONLY**
- (Recommended) Using a miniconda or venv virtual environment
- Basic familiarity with shell operations
